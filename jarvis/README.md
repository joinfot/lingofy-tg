# Джарвис — личный ассистент в Telegram

Расписание и смены, дела и напоминания, дорога по MVG, погода, утренний бриф, еда/калории/белок,
траты (в т.ч. гривны → евро), подготовка к экзамену с квизами, итог недели. Обновляется сам с GitHub.

## Установка (один раз)

1. Нужен Python 3.10+ (Windows: `winget install Python.Python.3.12`).
2. Распакуй архив в папку, например `Desktop\jarvis`.
3. Заполни `.env` (образец — `.env.example`): `TELEGRAM_TOKEN`, `OWNER_ID`, `ANTHROPIC_API_KEY`.
4. В папке: `py -m pip install -r requirements.txt`.
5. Запусти `start_jarvis.bat` (двойной клик). Он перезапускает бота после обновлений и сбоев.

Личные данные — `my_config.json`, `my_expenses.json`, `schedule.json`, `seed.json` — живут только локально
и при обновлении не трогаются. В репозитории лежит только код.

## Обновления

Раз в 3 минуты бот проверяет папку `jarvis/` на GitHub. Если там новый коммит — скачивает код,
пишет в Telegram «🔄 обновился» и перезапускается. Вручную: `/update`.

## Команды

`/day` еда и траты за сегодня · `/food` · `/money` · `/today` · `/week` · `/tasks` · `/exam` ·
`/report` · `/route` · `/morning` · `/status` · `/update`

Пиши обычным текстом: «кебаб 8 €», «вчера Lidl 12,50 — курица, рис», «завтра зал в 19»,
«во сколько завтра выходить?». Скрин банковского приложения — запишет все списания.
