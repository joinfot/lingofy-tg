# Сборка роликов Lingofy

Лежит здесь потому, что рабочая папка контейнера живёт только до
перезапуска: 6 ноября она стёрлась вместе со всем кодом, и день ушёл на
восстановление по памяти. Теперь код в репозитории.

Чего здесь нет и быть не должно: `mus/aglow.wav` — трек Олега, его надо
принести отдельно. Музыка в роликах только его, своей не генерируем.

## Как собрать партию

    export BATCH=accdata2            # содержание партии
    python3 vcut.py ПАПКА_С_ОЗВУЧКОЙ # опознать, нарезать, померить
    bash allacc2.sh                  # 15 роликов в /mnt/user-data/outputs

## Из чего состоит

| файл | что делает |
|---|---|
| `acc.py` | пять аккаунтов: шрифты, цвета, фон, плашка, голоса |
| `anim.py` | девять живых фонов, каждый — бесшовная петля |
| `mus.py` | подложка из трека: только громкость и срез, без своих слоёв |
| `fmts.py` | пять форматов: квиз, разбор, переписка, ошибка→верно, карточки |
| `accdataN.py` | содержание партии |
| `accrender.py` | кадры в jpg |
| `accaudio.py` | музыка плюс голос по местам |
| `ysplit.py` | нарезка дорожки на реплики по паузам |
| `vcut.py` | опознание файлов по длительности и нарезка |
| `vdurN.py` | эталонные длительности от ElevenLabs |

## Две вещи, на которых уже обжигались

**Голос опознаётся только по длительности.** Скачанные файлы называются
одинаково, а на слух я их не проверю. Один раз три дорожки встали не к тем
роликам, потому что сопоставлялись по числу знаков. Теперь `vcut.py`
сверяет каждый файл с эталоном и при первом несовпадении не режет ничего.

**Длина фазы считается от настоящей длительности реплики**, которая лежит
в `voice_real.json`. Оценка по числу знаков врёт в полтора-два раза, хуже
всего на числительных, и речь обрывается на полуслове.
